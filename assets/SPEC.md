# 美術規格（MVP v0.1 決策）

對應《遊戲美術資產需求清單 v0.1》第七節待確認問題，MVP 先採以下決策，可後續調整：

| 問題 | 決策 |
|---|---|
| Tile Size | 16×16 px |
| 角色尺寸 | 16×24 px／影格，腳底對齊底部中央 |
| 圖示 | 16×16 px；頭像 48×48 px |
| 角色結構 | 單張完整 Sprite（不分層）；NPC 共用身體模板，以換色／髮型區分 |
| 動畫 | 橫向 Sprite Sheet，影格由左至右；行走 4 格、待機 2 格；左向＝右向水平翻轉 |
| 第一種工作 | 咖啡店店員（節奏小遊戲主題：咖啡杯／點單） |
| UI | 像素框九宮格面板（24×24，邊框 8px） |
| 輸出 | PNG 原生解析度，引擎以 nearest-neighbor 放大 |
| 調色盤 | 固定於 `tools/pixel.py` 的 `P` |
| 命名 | `類別_ID_名稱_方向_動作_v01.png` |

產生方式：`python3 tools/gen_*.py`，全部素材由程式產生，可重複生成。
