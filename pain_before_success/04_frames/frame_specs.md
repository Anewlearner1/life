# 首尾幀文字稿 v1（先寫再畫；通過審核才出圖）

規格：1920x1080（16:9）、畫風＝`03_design/style_sample_v1.png`、角色＝`03_design/design_canon.md`。
每鏡都要寫：首幀畫什麼、尾幀畫什麼、中間發生什麼。**先畫資訊最多的一張（多半是尾幀），再用它當參考改出另一張，背景與機位鎖死。**
S2 的推近、S4 的拉遠只有 5%，用 Python 裁切放大做，不叫 ChatGPT 畫。

左右一律指畫面左右。「右鞋」＝穿鞋者的右腳鞋（鞋尖朝鏡頭時在畫面左側）。

## S1　雨夜摔倒（生成 8 秒，取 0.3–5.63 秒）
- 場景：雨夜田徑場，濕的沙褐跑道（#4A3C32），身後橘黃鈉燈逆光＋亮雨霧光暈（#C27A40），雨絲、積水反光。
- 機位：貼地低機位、正面略偏左，中全景（看得到雙腳）。
- **首幀**：小晴（背心短褲、**舊鞋**）在畫面中段（頭在 62%）朝鏡頭方向跑，身形被逆光勾出亮輪廓，臉有暖色補光、極度疲憊；跑道上有積水反光。
- **中間**：約生成第 1.2 秒，她腿一軟、畫面左側那隻腳（右腳）的鞋頭拖地，往前撲倒，雙手撐地、膝蓋著地，水花濺起。
- **尾幀**：她跪撐在濕跑道上低頭喘氣，頭仍在約 62%，身後保留光暈與積水反光（避免身體融進暗跑道）；雨持續。右鞋鞋頭此時有洞，但鞋在逆光暗處看不清，不要特寫。
- 先畫：尾幀（跪撐）→ 改首幀（站著跑）。
- 注意：舊鞋兩隻，不要多出第三隻；不要有文字。

## S2　臥室放鞋（生成 8 秒，取 1.0–6.33 秒）
- 場景：臥室，暖黃檯燈（左上），牆 #5E4232、深色木地板 #4E3424，床單深靛 #3A3550。
- 機位：床沿高度（低機位）、側面中景；極慢推近 5%（Python 裁切）。
- 構圖：床在畫面左側；小晴在床上側睡面向鏡頭，臉約在 30%；媽媽蹲在畫面右側，頭在 62%，四分之三側臉朝左。
- **首幀**：小晴穿淺灰 T 恤、深灰短褲側睡，腿沒蓋被，兩膝各一塊純白方形紗布清楚可見。前景地板：舊鞋一雙（破洞鞋在畫面左側、洞朝鏡頭）。媽媽蹲著，眼眶泛紅，左右手各拿一隻紅鞋（鞋尖朝畫面左），低頭看舊鞋。舊鞋的**畫面右側**留一塊鞋子大小的空地板，在媽媽身前、她一臂之內。
- **中間**：媽媽抬頭看熟睡的女兒，再低頭把兩隻紅鞋輕輕放在舊鞋右邊的空地上。**約第 5.5 秒前放好。**
- **尾幀**：兩雙鞋並排：舊鞋（左）＋紅鞋（右），共四隻；媽媽的手剛離開紅鞋，看向女兒。小晴姿勢、床、檯燈完全不變。
- 先畫：尾幀（四隻鞋並排）→ 改首幀（紅鞋回到媽媽手中、空地板）。
- 注意：首尾幀鞋子數量必須核對：首幀舊鞋 2＋手中 2、尾幀地上 4；媽媽不插口袋、臉不背對鏡頭。

## S3　冬晨慢跑（生成 8 秒，取 1.0–6.33 秒）
- 場景：冬天清晨霧中田徑場，霧 #E6C49B、沙褐跑道 #D2B48C，金色朝陽光從畫面右後方斜來（**太陽在畫面外，只留光**），欄杆與燈柱一路排開。
- 機位：側面中景跟拍，與人同速向右橫移。
- 構圖：小晴由左往右慢跑，頭固定在約 38%。冬裝（深藍長袖防風外套、黑長褲、紅鞋＋白底）。
- **首幀**：她的腿在跨步相位 A；背景有幾根欄杆柱，霧較濃。呼出白氣。
- **尾幀**：人物位置、大小、光線完全相同；腿在不同步態相位 B；**背景欄杆柱相對首幀位移約 2 根的距離**，遠景（霧、樹影）移得少、近景（欄杆）移得多，做出視差；呼出白氣。
- 先畫：首幀 → 用它當參考，請 ChatGPT 改成「同一個人同一件衣服，同樣位置，只換腿的相位，背景往左移」。若背景位移畫不準，由我用 Python 把背景切片移動後把人貼回。
- 注意：首幀必須有人（不要空景）；人物不背對鏡頭；兩隻紅鞋。

## S4　夕陽草地睜眼（生成 8 秒，取 0.3–5.63 秒）
- 場景：夏天傍晚跑道內側草地（深橄欖 #3E4820），橘紅夕陽**從畫面右側斜照**（畫面裡看不到太陽），草上有長影。
- 機位：正上方俯拍、特寫、臉朝上；頭朝畫面上方，眼睛在約 62%；極慢拉遠 5%（Python 裁切）。
- 構圖：小晴仰躺，馬尾從頭後散在草上（黑髮、無散絲），穿深藍背心；臉被夕陽直射（最亮處）。臉旁草葉被風吹動。
- **首幀**：閉眼、嘴微張大口喘氣、額頭有汗（不畫汗滴符號）。
- **中間**：約生成第 2.97 秒（片中 0:18.67）慢慢睜眼看天空，嘴角慢慢上揚。
- **尾幀**：睜眼、淺淺微笑，胸口起伏變緩；構圖與首幀一致。
- 先畫：尾幀（睜眼微笑）→ 只改眼睛與嘴出首幀。
- 注意：臉是正的、五官不上下顛倒；沒有太陽入鏡。

## S5　衝線（慢動作，生成 8 秒，取 1.3–6.63 秒；撞線在生成第 4.0 秒）
- 場景：比賽日晴朗午後，金色側逆光（從畫面左後方），沙褐跑道，天空 #F3D28C；臉部有暖色補光、表情清楚。
- 機位：低機位、長焦，從終點線右前方約 30° 斜拍、固定。整段慢動作（約 0.4 倍速）。
- **首幀**：小晴（比賽服＋素面白號碼布、紅鞋）在遠處，從畫面左後方往右前方斜向全力衝刺，全身入鏡，頭約在 38%；白色終點帶（畫寬一點）橫在畫面中後段、離鏡頭約三分之二遠，兩端由畫面外的裁判拉著；只有**兩名**對手，模糊、落後在她身後更遠處、都在畫面右側（75% 以右），不與她交叉。
- **中間**：她持續衝刺，約生成第 4.0 秒胸口撞斷終點帶，雙臂順勢張開；動態來源：頭髮與號碼布邊緣被風吹動。
- **尾幀**：她剛衝過終點帶、仍在跑、雙臂張開、仰頭；人物仍是全身、頭不超過畫面 50%；終點帶斷成兩截，先隨她往前飄、再往畫面左右兩側垂落；對手仍在 75% 以右。
- 先畫：尾幀（資訊最多）→ 改首幀（帶子完整、人在遠處）。
- 注意：號碼布素白無字；不要多出對手；帶子斷成兩截而不是消失。

## S6　看台含淚笑（生成 8 秒，取 0.3–5.63 秒）
- 場景：看台，同一個金色午後，背景 #9C6A44（陰影處）、座椅 #A87850。
- 機位：平視正面、中近景、固定（全片唯一的平視正面）。
- 構圖：媽媽站在畫面左側，頭在 38%；坐著的阿姨在畫面右側約 70%，臉朝畫面左下方的跑道。背景只有三四個很遠、很模糊的觀眾，姿勢各不同（一人舉手、一人拍手、一人站著）。
- **首幀**：媽媽雙手把洗乾淨的舊鞋抱在胸前（破洞鞋的洞朝鏡頭，破洞在畫面左側那隻），看向畫面左下方的跑道，表情緊繃（看到女兒衝線的那一刻）。阿姨也看向畫面左下方。
- **中間**：媽媽眼淚掉下來，表情從緊繃變成含淚的笑（抱鞋姿勢不變）。隔一拍，坐著的阿姨抬頭往畫面左上方看向站著的媽媽，微笑鼓掌。
- **尾幀**：媽媽含淚笑、抱鞋；阿姨看著她微笑鼓掌。
- 先畫：尾幀 → 改首幀。
- 注意：舊鞋只有兩隻、媽媽不插口袋；媽媽不要背對鏡頭；背景觀眾不要同一個姿勢。
